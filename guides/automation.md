# What is automated

Research and drafts write to the **private** repo `GrapheneFacts/graphene-facts-archive`.

This public repo is updated only after a human “publish” step.

| Job | Time (ET) | Writes |
|-----|-----------|--------|
| Daily research + themed draft | 05:00 | private `daily/` + `drafts/` |
| Sunday thread draft | 07:00 | private `drafts/` + `weekly/` |
| Sunday full compile | 09:00 | private `weekly/` |

X posting is still manual. There is no auto-tweet.
