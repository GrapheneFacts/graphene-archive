# Evidence labels

| Label | Use when |
|-------|----------|
| **Well-supported** | Peer-reviewed paper, official regulator text, confirmed commercial order |
| **Preliminary** | Preprint, company lab data, pilot/small-cell results |
| **Unverified** | Assertion without solid primary source |
| **Fringe** | Conspiracy-style narratives; document only |

Folder placement (research, industry, fringe, …) is for **browsing**. The label is for **confidence**.
